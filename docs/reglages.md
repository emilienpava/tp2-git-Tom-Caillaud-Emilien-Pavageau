# Réglages de releve-cli

Ce document présente les principaux réglages utilisés par `releve-cli`.

| Réglage          | Valeur par défaut      | Valeurs acceptées               | Rôle                                     |
| ---------------- | ---------------------- | ------------------------------- | ---------------------------------------- |
| `CHEMIN_RELEVES` | `exemples/releves.csv` | Chemin vers un fichier existant | Indique le fichier de relevés à traiter. |
| `INTERVALLE`     | `300`                  | Nombre entier, en secondes      | Définit le délai entre deux rapports.    |

> Les valeurs réelles utilisées dans l'environnement de travail doivent être renseignées dans `config.txt`. Elles ne doivent pas être ajoutées à ce document ni publiées dans le dépôt.
